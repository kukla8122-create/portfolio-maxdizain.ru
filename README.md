# МАКСимум мебель — дизайн и мебель на заказ

Официальный сайт интерьерной студии и собственного мебельного производства **«МАКСимум мебель»** (Нижний Новгород).

Проектируем кухни, шкафы и гардеробные, готовим 3D-визуализацию, технические проекты мебели с размерами. Работаем с 2012 года. Производство и сборка корпусной мебели — Нижегородская область; дизайн-проекты интерьеров — дистанционно по России.
