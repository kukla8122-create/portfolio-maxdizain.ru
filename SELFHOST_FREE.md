# МАКСимум мебель — самостоятельный MAX-бот без платного конструктора

Рабочая ветка: `maxbot-production`.

## Что запускается

`maxbot-selfhosted.py` — самостоятельный MAX Bot API webhook-сервис:

- API: `https://platform-api2.max.ru`;
- Webhook: `POST /webhook`;
- health-check: `GET /health`;
- проверка `X-Max-Bot-Api-Secret`;
- callback-кнопки с обязательным ответом через `/answers`;
- `request_contact` для получения номера клиента;
- проверка HMAC-SHA256 контакта;
- заявки на кухню, шкаф и дизайн-проект;
- FAQ и сохранение нестандартных вопросов;
- SQLite в `/app/data/maxbot.db`;
- 20 фото портфолио с `portfolio-maxdizain.ru`;
- сохранение `chat_id` канала/чата при событии `bot_added`.

## Секреты

НИКОГДА не добавлять токены в Git и не отправлять их в чат.

В панели хостинга создать переменные окружения:

```text
MAX_BOT_TOKEN=<реальный токен MAX>
MAX_WEBHOOK_SECRET=<отдельная случайная строка 32+ символа: A-Z a-z 0-9 _ ->
DATABASE_PATH=/app/data/maxbot.db
MAX_AUTO_SUBSCRIBE=1
```

Хостинг обычно задаёт `PORT` автоматически. Приложение читает `PORT` и слушает `0.0.0.0`.

После получения публичного HTTPS-домена добавить одну из переменных:

```text
DOMAIN=<автоматический домен хостинга>
```

или

```text
PUBLIC_BASE_URL=https://<автоматический домен хостинга>
```

Тогда сервис сам проверит текущие подписки MAX и зарегистрирует:

```text
https://<домен>/webhook
```

Опционально после первого теста можно добавить:

```text
MAX_ADMIN_CHAT_ID=<chat_id диалога Катерины с ботом>
```

Тогда новые заявки будут дополнительно приходить Катерине в MAX.

## Docker

В корне ветки есть `Dockerfile`. Он:

1. использует Python 3.12 slim;
2. устанавливает системные CA + `curl`;
3. добавляет корневой и промежуточный сертификаты Минцифры;
4. запускает `maxbot-selfhosted.py`;
5. не требует сторонних Python-библиотек.

`.dockerignore` оставляет в build context только `Dockerfile` и `maxbot-selfhosted.py`.

## Вариант бесплатного размещения: Bothost

Проверяем только бесплатный Starter. Ничего не оплачиваем.

Параметры проекта:

```text
Git repository: https://github.com/kukla8122-create/portfolio-maxdizain.ru.git
Branch: maxbot-production
Custom Dockerfile: ON
Use domain: ON (только если доступно на бесплатном Starter)
Internal port: значение PORT, обычно 8000
```

После деплоя:

1. открыть `https://<домен>/health`;
2. ожидать JSON с `"ok": true`;
3. посмотреть runtime-логи;
4. убедиться, что есть строка `MAX webhook subscribe: 200 ...` или `MAX webhook already subscribed`;
5. открыть MAX и нажать «Начать» у бота;
6. проверить все 8 кнопок и заявки;
7. только после этого добавить бота в канал и выдать нужные права администратора.

Если бесплатный Starter не позволяет включить публичный HTTPS-домен/Webhook, НИЧЕГО НЕ ОПЛАЧИВАТЬ: останавливаемся и выбираем другой бесплатный хостинг.

## Канал MAX

Webhook подписан на `bot_added`. После добавления бота в канал событие содержит `chat_id` и `is_channel=true`; бот сохранит это в SQLite.

Для полноценной работы в канале бот должен быть администратором с правами, необходимыми сценарию. Минимально для публикации/получения событий обычно нужны `read_all_messages` и `write` согласно актуальной документации MAX.

Интерактивные заявки пользователей лучше вести в личном диалоге с ботом, а канал использовать для публикаций/перехода в бота.

## GigaChat

В бесплатную production-версию GigaChat намеренно НЕ включён.

Причина: текущие условия GigaChat разрешают Freemium-контент только для личного некоммерческого использования. Бот «МАКСимум мебель» используется коммерчески. Чтобы не нарушать условия и не платить, ветка «Задать вопрос» сейчас:

- отвечает на известные FAQ;
- сохраняет нестандартный вопрос и контакт клиента для ответа Катерины.

ИИ можно подключить позже только при наличии подходящих коммерческих условий использования.

## Важные правила переключения

- Production MAX = Webhook.
- Не держать одновременно Webhook и Long Polling.
- Старый VPS/старый Long Polling не удалять до успешного теста нового сервиса.
- После успешного нового запуска проверить `GET /subscriptions` и удалить старую webhook-подписку, если она осталась.
- При подозрении на утечку токена перевыпустить его в MAX для бизнеса и обновить только переменную окружения хостинга.
