Кто обрабатывает данные

Какие данные собираются

При отправке заявки: имя, контактный телефон, интересующая услуга, адрес страницы сайта и, если указаны в ссылке, источник и рекламная кампания. Для ограничения спама технически формируется обезличенный криптографический хеш сетевого адреса; сам IP-адрес в таблице заявок не хранится.

Зачем нужны данные

Чтобы связаться с вами по запросу, подготовить предложение, организовать работу по проекту и учитывать обращения. Контактные данные не публикуются на сайте и не используются для массовой рекламной рассылки без отдельного согласия.

Где обрабатываются данные

Данные формы передаются через защищённое HTTPS-соединение и сохраняются в ограниченной для посетителей сайта системе учёта заявок. Техническая инфраструктура обработки заявок использует облачный сервис Supabase с размещением в Европейском союзе. Персональные данные могут быть доступны только уполномоченным для обработки обращения лицам и техническим поставщикам.

Срок хранения и удаление

Данные хранятся на срок, необходимый для обработки обращения и выполнения обязательств, либо до получения запроса на удаление, если дальнейшее хранение не требуется по закону. Вы вправе запросить информацию о своих данных, их исправление или удаление, написав на mebelmaksimum@mail.ru.

Согласие

Перед отправкой заявки посетитель ставит отдельную отметку согласия на обработку данных для ответа на обращение. Без отметки автоматическая отправка невозможна.

Статистика сайта

Для измерения посещаемости и работы сайта применяются системы веб-аналитики. Не передавайте паспортные данные, банковские реквизиты и иную конфиденциальную информацию через форму заявки.
